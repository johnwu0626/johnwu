# 9527：星際遠征（精緻化重製版）

本專案為針對 `https://game.tbgofire.com/games/9527/`（原版 Godot 4.7 Web 匯出版本）所打造的**全方位精緻化 Web 版**。保留原版所有核心企劃設定、寫實機體／Boss 美術貼圖與原創配樂，並徹底重構 UI 字型、視覺光影特效、12 關環境演出與雙重混音音訊引擎。

## 四大精緻化升級亮點

1. **UI 與字型全面科幻化（告別標楷體 `TW-Kai.ttf`）**
   - 採用 `Orbitron`、`Chakra Petch`、`Noto Sans TC` 與 `JetBrains Mono` 打造高對比科幻戰術機庫與 HUD。
   - 機庫內建 **3 架戰機即時全息預覽與四維性能圖表**、**12 關星圖航線跳選器**、**雙僚機與自動連射切換**。
   - **Boss 雙層血條系統**：清晰區分「外殼護甲 (OUTER SHELL)」與「核心反應爐 (CORE)」，破殼時觸發專屬慢動作與閃光提示。

2. **戰鬥視覺與打擊感升級**
   - 內建智慧貼圖淨化器（`SpriteManager`），自動將原版 `.pck` 解包之戰機、敵機與 12 關 Boss 貼圖去背與邊界裁切，並加上雙噴嘴動態尾焰、機身傾斜（Banking）、受擊白閃、無敵六角護盾與擊破粒子爆炸。
   - **10 段火力進化（Lv.1 ～ Lv.10）**：游隼（高速電漿矛＋導引飛彈）、稜鏡（廣角扇射＋懸浮折射片）、重錨（穿甲磁軌重砲＋破甲守衛彈）每級皆有明顯彈道成長。
   - **機體火力展示 ＆ Boss 模擬室 (`[V]`)**：可隨時切換 Lv.1～Lv.10、試放必殺炸彈，並直接召喚第 1～12 關任一 Boss 試打。

3. **12 關環境機制與視差背景強化**
   - 完整實作地球軌道篇（S01–S03）、月球補給篇（S04–S06）、深空轉移篇（S07–S09）、火星降臨篇（S10–S12）。
   - 包含 **第五關中繼訊號短斷＋鏡面折返彈**、**第六關過關炸彈補給**、**第七／八關微流星航道預警線**、**第九關太陽風冷卻延長帶**、**第十一關火星大氣熱流與通風廊道**，以及 **第十二關「護航修復核心跟隨琥珀信標降落曙光前哨站」終局演出**。

4. **雙重混音音效引擎（Hybrid WAV + Web Audio Synthesizer）**
   - 結合原版解包之 4 首立體聲 BGM 與 16 組 WAV 音效，並以 Web Audio API 疊加立體聲左右定位（Stereo Panning）、低頻重擊與動態壓縮防爆音保護。
   - 提供獨立 BGM / SFX 音量滑桿、靜音開關與 **「減少動態 (Reduced Motion)」** 視覺保護模式。

## 本機啟動方式

```bash
npx http-server game/9527 -p 8095 -c-1
```
開啟瀏覽器前往 `http://localhost:8095/` 即可遊玩。
